# 2.17.0

## Work item comment corrections

- Correct or retract product-context decisions this agent previously recorded on affected planning tickets.
- Every correction supplies the last observed comment revision, so a concurrent edit is rejected rather than overwritten.
- Corrections stay limited to comments this installation authored. The agent cannot edit or delete a comment written by a human reviewer or another agent.
- A retracted comment disappears from the board and ticket views while its activity and audit history is retained.
- Request two comment permissions during the normal installation or upgrade review. Existing installations must approve the new access before the correction tools become available.
- Update to Agent SDK 3.47.0. No breaking configuration changes.
