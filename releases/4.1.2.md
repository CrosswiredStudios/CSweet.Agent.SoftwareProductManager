# 4.1.2

Declare two adapter-only read requirements used by existing-project management:
`platform.project-assignment.read.v1` supplies the caller's server-resolved assignment, and
`platform.workstream.read.v1` verifies current project status and accountable management.
Both remain hidden from model tools and require reviewed installation grants. Existing
participant, management and mutation checks remain in force.

Delivery regression fixtures now register only capabilities declared by the packaged manifest.
They exercise assignment reads, retained-project chat routing and isolated delivery preparation,
including denial before mutations when either project-context read is revoked.
