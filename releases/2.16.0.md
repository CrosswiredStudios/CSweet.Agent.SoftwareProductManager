# 2.16.0

## Business calendar

- Query, create, edit and cancel events in the shared business calendar through approved model tools.
- Schedule tracked work for yourself or workers within your existing reporting authority. Scheduling does not grant execution permissions or bypass work approvals.
- Receive calendar reminders and scheduled-work notifications through the agent runtime.
- Request five calendar permissions during the normal installation or upgrade review. Existing installations must approve the new access before calendar tools become available.
- Update to Agent SDK 3.40.0 and the typed calendar contracts. No breaking configuration changes.
