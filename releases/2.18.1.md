# 2.18.1

## Configurable Product Manager token budgets

- Expose a maximum context-window planning ceiling (default 220,000 tokens) and a maximum per-response output budget (default 32,000 tokens) in installation configuration.
- Apply the output budget to model responses, clamped below the configured context ceiling. Bounded staffing (resource-change-only) turns keep the fixed 2,000-token budget.
- These settings do not expand the selected model's actual context window or provider output allowance. No new capabilities or permissions are requested.
